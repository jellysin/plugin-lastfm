# Acceptance criteria

This list states what the plugin must do to count as a complete product, one criterion
per row of the feature list in [issue 96](https://github.com/jellysin/plugin-lastfm/issues/96),
which the maintainer approved on 2026-10-13. It covers the rows D1, D2, G1, G2, G4,
P1 to P5 and O1 to O6. Each criterion names the test that proves it, or a recorded CI
run of the server checks; a row without proof names the gap. `tools/acceptance.py`
checks that every named file, test name, heading and row exists, and the Python test
suite runs it on every change.
