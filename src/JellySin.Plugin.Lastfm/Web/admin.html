Server settings

Media types to scrobble
A track with several artists is sent as "A, B & C" instead of under its first artist. Last.fm keeps that credit as an artist of its own.
Trailing featured credits such as "(feat. B)", "[feat. B]", "feat. B" or "- feat. B" are removed from track titles and artists before scrobbling and now playing.
Tracks without a valid MusicBrainz recording ID are skipped and neither scrobbled nor sent as now playing.
When a play counts

Last.fm counts a track longer than 30 seconds once half of it or 4 minutes, whichever comes first, has been heard. These settings can only make that stricter.

Advanced: Last.fm application

Release builds include the project's Last.fm application, so most servers need nothing here. A server may use its own application instead; it is stored protected on this server and never shown again.

Remove the application override stored on this server? The server then uses the application included with this build, if there is one. Connected accounts must connect again.
